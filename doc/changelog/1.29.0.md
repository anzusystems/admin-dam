1.29.0 — 2026-06-15
===

### Features

#### Text-to-speech (synthetic audio)

- **Voice family settings module** — full CRUD (list / detail / edit) for voice
  families, with ext-system and language selects, keyword + auto-keyword support
- **Per-provider voice management** — split voice forms for ElevenLabs and Google
  TTS (by discriminator), voice bindings create/edit dialogs, provider toggle
- **TTS narration requests** — synthesize view and job datatable with filter,
  request detail view showing per-chunk progress, status auto-polling, request
  mode / status / audio-status chips, and a cancel-request dialog
- **Synthesize action** — `ACreateDialog`-based synthesize with cascading
  voice-family / voice selects, ext-system on request, licence selection
- **Asset detail TTS sidebar** — TTS panel in asset detail, podcast multi-select
  widget, `ttsAudio` grid meta-icon (`mdi-text-to-speech`)
- **Ext-system TTS settings** — TTS settings form with default voice family,
  ElevenLabs model constant, and free-audio-epilog asset
- New routes, API services, stores, value objects and EN/SK translations for
  voice, voice family and TTS narration request

#### Public export

- Public export now supports multiple licences (binds to a licences array)

### Bug Fixes

- voice-edit dialog reset and synthesize podcast scope
- TTS request detail poll cleanup and cascade race guards
- Slovak pluralization for failed-chunk count
- surface TTS request detail load errors
- bump axios / postcss / uuid / vite to patch audit vulnerabilities
