2.1.0 — 2026-08-17
===

### Fixed

- **Redirects from the pre-2.0.0 route paths.** 2.0.0 pluralized every route path and shipped no
  redirect layer, so every link and bookmark created before it landed on the not-found page. All 20
  renamed roots now redirect to their current path, including the segment that was renamed one level
  deeper (`/podcast/:id/episode/:episodeId` → `/podcasts/:id/episodes/:episodeId`). Params, query and
  hash are preserved. Paths 2.0.0 left alone (`/login`, `/logout`, `/settings`, `/close-page`,
  `/unauthorized`) are untouched.

  The shim in `src/router/legacyRedirects.ts` is temporary and names the link sources that have to
  change before it can be dropped: `DamAdminAssetLink.vue` in common-admin (rendered by admin-cms in
  the audio widget and the audio/video embed dialogs, by common-admin itself in the image detail
  dialog, and inherited by admin-ugc) and admin-cms' `DAM_USER_EDIT_URL_TEMPLATE`, whose value also
  lives in every developer's `.env.local`, the generated `public/config.json` and the deployment
  pipeline variables.
