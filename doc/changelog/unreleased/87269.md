Single use badge
===

### Added

- **A "1×" badge on single use assets.** The badge shows on the tile and in the Info column of the table row of the asset list. It shows when the main file of the asset is single use.

### Changed

- **The image preview picker offers no single use photos.**

### Fixed

- **The "1×" badge updates after saving metadata.** Saving metadata in the list sidebar or in the asset detail sidebar updates the badge of the saved asset in the list without a reload. The other assets of its take over group update after a reload.
- **The upload queue keeps the saved single use.** Saving an asset opened from the upload queue passes the new value to the queue, so a later save of the queue does not send the old one.
