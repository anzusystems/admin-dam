planned

### Changed

- **"User in external systems" in the user edit form is read-only.** DAM sets it on every save from the user's licences and licence groups, so a value picked in the form was dropped. The form shows it as chips, like the user detail, and refreshes them after save. Access to a whole external system, for example for a system user, goes through "Admin in external systems".
- **A long asset title no longer pushes the toolbar buttons out of the asset detail.** The title in the asset detail, the file detail and the external provider asset detail is cut to one line, and the full title shows in a tooltip.

### Fixed

- **The "Confirm" button in the licence selection dialog shows a loading state while it saves,** so a second click does not send the request again.
- **A leftover `console.log` in the licence selection dialog is gone.**
