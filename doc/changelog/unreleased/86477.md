planned
===

### Added

- **Default source and enforced single use in the licence form.** The licence form and detail show the default source, picked only from sources, and the switch "Vynútené jednorazové použitie". New and updated files of such a licence are always single use. Needs core-dam with `defaultSource` and `flags.singleUseEnforced` on the licence.

### Changed

- **The automatic deletion date only in the asset detail.** The asset tile and list row no longer show the badge with the remaining time. The file info shows the date with the remaining time under the shorter label "Zmaže sa", so the label no longer runs into the date.
