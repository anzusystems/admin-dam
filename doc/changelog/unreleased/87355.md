Sources of an image
===

Needs core-dam-bundle 1.58.0 and common-admin 1.51.0.

### Added

- **A Sources section.** An admin can create, edit and delete sources. A source is an author that only gives the credit of an image, for example a news agency. The section is visible only with the `DAM_SOURCE_UI` permission. The buttons use the `DAM_SOURCE_CREATE`, `DAM_SOURCE_UPDATE` and `DAM_SOURCE_DELETE` permissions.
- **A Sources field on the asset detail and in the upload queue.** The field shows only when the ext system has sources enabled for the asset type. The mass operations of the upload queue fill sources too.
- **The asset filter `sourceIds`.** The asset list can filter assets by their sources.

### Changed

- **The Authors section shows authors only.** Sources have their own section.
- **A source found with the "+" button in the Authors field goes to the Sources field.** The admin gets a message. Fields without a Sources field keep adding the found source to authors.
