Sources of an image
===

Needs core-dam-bundle 1.58.0 and common-admin 1.51.0.

### Added

- **A Sources section.** An admin can create and edit sources. A source is an author that only gives the credit of an image, for example a news agency. The menu item shows only with the `DAM_SOURCE_UI` permission. The buttons use the `DAM_SOURCE_CREATE` and `DAM_SOURCE_UPDATE` permissions.
- **A Sources field on the asset detail and in the upload queue.** The field shows only when the ext system has sources enabled for the asset type. The mass operations of the upload queue fill sources too.
- **The "+" button in the Sources field.** It creates a source and needs the `DAM_SOURCE_CREATE` permission.
- **The asset filter `sourceIds`.** The asset list can filter assets by their sources.

### Changed

- **The Authors section lists authors and sources together.** The Sources section lists sources only. The Authors list has a Source filter and a Source column. A row opens the detail of its own kind.
- **Sources and Authors sit in one row with a slash between them.** This holds on the asset detail, in the upload queue and in the bulk edit. The Sources field offers the first 25 sources when the admin opens it. Typing finds the others.
- **Every author can be hidden in the credit.** The "Hidden in credit" switch, detail row and list column show for authors too, not only for sources.
- **The "+" button moves an existing record to the field of its kind.** A source found from the Authors field goes to the Sources field, and an author found from the Sources field goes to the Authors field. The admin gets a message. Fields without a Sources field keep adding the found source to authors.
- **The Authors and Sources lists answer the same way.** When "+" in the Authors list finds a source, the admin gets "already exists as a source". The Sources list does the same for an author. When "+" finds a merged author, the admin gets "already exists and is merged".
- **Author fields and filters do not offer merged authors.**
- **The `authorIds` filter of the asset list offers authors and sources.** Its label is "Authors and sources". The `sourceIds` filter offers only sources.
