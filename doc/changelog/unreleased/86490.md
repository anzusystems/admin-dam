planned
===

### Added

- **Asset list views.** An admin can define a list view with licence groups, licences and an upload licence chosen from those licences, under Settings. The user switches the view in the top bar. The asset list searches across all licences of the view, and uploading is allowed only when the view has an upload licence. The switch shows the upload licence of every view. In a view without one, the upload button is disabled and its tooltip says why. When an upload or a selection is in progress, the switch asks before it reloads the page.
- **A short licence badge.** The licence has an optional badge of up to 4 characters (A-Z, 0-9). It shows on the asset tile and in the asset list row when the list view has more than one licence. The asset detail shows the licence name.
- **The date of the automatic deletion of an asset, read from DAM.** The asset detail shows the date, and the asset tile and list row show a badge with the remaining time. The row and the badge stay hidden when DAM does not send the field.
- **The main file EXIF in the asset detail and in the asset list sidebar.** The Info tab and the right panel of the asset list show a collapsible "Main file EXIF" panel under "File info", with the key and value of every EXIF entry. It shows for every image asset; an image without EXIF data shows 0 and the panel is disabled.

### Changed

- **The name of an asset licence can have 2 characters.** It needed 3 before.
- **The ext system of an asset licence is read-only on its edit form.** DAM sets it only when the licence is created.
- **The external providers are in the options menu.** They moved from the top bar menu, which the list view switch replaces. Their links stay reachable for users with the access permission.
- **Sorting of the asset list is a toggle on desktop.** The toggle shows every sort option at once and marks the active one. Small screens keep the dropdown.
