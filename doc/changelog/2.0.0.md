2.0.0 — 2026-08-17
===

Major frontend-stack upgrade: Vuetify 4, vue-router 5 with file-based routing, pinia 4 and `@anzusystems/common-admin` v2 (`/labs` API), plus a domain-driven restructure of `src/`. Items marked **Breaking** change URLs or public structure — read them before deploying. Released via [PR #259](https://github.com/anzusystems/admin-dam/pull/259); all changes by @volarname.

### Added

- **Voice Family settings module** — new DAM entity (list / detail / create / edit) including the voice-bindings sub-list. [[#84735](https://dev.azure.com/petitpress/Anzu/_workitems/edit/84735)]
- **Active-filter chips on the asset grid** — applied sidebar filters appear as removable chips in a bar under the toolbar on `/assets` (reuses common-admin `FiltersSelected`, teleported out of the sidebar scope). The `type` filter is excluded (it has dedicated toolbar toggles), the reset button clears the chips, and **Enter** in any sidebar field submits the filter. [[#85491](https://dev.azure.com/petitpress/Anzu/_workitems/edit/85491)]
- **`mainFileInternal` asset filter + internal-image support.** [[#73441](https://dev.azure.com/petitpress/Anzu/_workitems/edit/73441), [#84581](https://dev.azure.com/petitpress/Anzu/_workitems/edit/84581)]
- **oxlint + oxfmt** toolchain (`.oxlintrc.json`, `.oxfmtrc.json`, `format` / `lint:oxlint` scripts).
- **lightningcss** CSS transformer/minifier and **browserslist** (`.browserslistrc`, `browserslist:update`), `build.target: es2019`.
- **eslint-plugin-vuetify** (`flat/recommended-v4`).
- **unplugin-auto-import** — auto-imports `vue` / `vue-router` / `pinia` / `useI18n` / `useVuelidate` plus a curated set of common-admin helpers and types (generated `src/auto-imports.d.ts`). Removed ~6.6k lines of import boilerplate across ~530 files.
- **Typed file-based router** (`vue-router/vite`, generated `src/typed-router.d.ts`, `scripts/generate-dts.mjs` + `generate:dts`) and a local ESLint rule `anzu-local/valid-route-name` validating route-name literals against the typed map.
- **Shared anzu ESLint plugin** from common-admin (`anzu/no-fatal-error-axios-check`, `anzu/url-params-match-template`, `anzu/no-deprecated-imports`). The deprecated-barrel migration landed in this release (191 files), so the last rule is enforced as `error` with no skip list and no remaining hits.
- **ESLint guard against a bare `validateAll()`** (`no-restricted-syntax`) — a bare call discards its boolean and does *not* block save; callers must gate on it (`if (x.validateAll() === false) return`) or pass `:validation-scope`. [[#85050](https://dev.azure.com/petitpress/Anzu/_workitems/edit/85050)]
- **Manual Rollup chunking** — `vue-core`, `vue-i18n`, `vuetify`, `common-admin`, `tiptap`, `realtime`, `sentry`, `vendor-utils` chunks with readable filenames; the 1.6 MB monolith chunk is gone.
- `watch-common-admin` Vite plugin for HMR against a locally linked common-admin, a `build:dev` (unminified) script, and `lint:tsc` switched to `vue-tsc --build` (project references, incremental).
- Breadcrumbs reworked to an explicit `<ActionbarWrapper :breadcrumbs>` + `defineBreadcrumbs(...)`, which restores multi-level chains (e.g. `Podcasts → Podcast detail → Episode`).

### Changed

- **Route paths are pluralized** (admin-cms convention): `/asset` → `/assets`, `/user` → `/users`, `/author` → `/authors`, `/podcast` → `/podcasts`, … for every entity. **Breaking: existing bookmarks to the old singular URLs now 404 — no redirect layer was added.**
- **Vuetify 3 → 4.** MD2 → MD3 typography, grid props replaced by utility classes, `dark` / `contain` props removed, theme-color alpha syntax changed (`rgb(var(--v-theme-X), 0.Y)` → `rgb(var(--v-theme-X) / Y%)`). A `@layer vuetify-core.reset { … }` block restores the v3-style universal/form-element reset that v4 dropped. **Breaking.**
- **vue-router 4 → 5 + file-based routing.** The manual `src/router/routes/` (21 files) and the `ROUTE` constants are replaced by a `src/pages/` tree (`(coreDam)` / `(common)` groups, per-page `definePage({ meta })`); router guards migrated from `next()` callbacks to return values. **Breaking.**
- **`@anzusystems/common-admin` v2 (`/labs` API).** Imports moved off the deprecated barrel to `@anzusystems/common-admin/labs`; filters, datatables, pagination, list editors and API helpers all use the v2 API. **Breaking.**
- **pinia 3 → 4. Breaking.**
- **Domain-driven `src/` restructure.** New `src/domains/<system>/<entity>/{api,components,composables,factory,filter,store,types,valueObject}` layout (systems: `system/`, `common/`, `coreDam/`) with cross-system generics in `src/shared/`. The top-level `src/{components,composables,services,stores,types,model,views,utils}/` folders are gone. ~800 files moved via `git mv` (history preserved), ~700 import sites rewritten. **Breaking.**
- **Filter persistence is disabled on all admin-dam lists** — `useFilterHelpers(…, { populateUrlParams: false, storeFiltersLocalStorage: false })` on all 22 datatables. URL-hash / bookmark restoration is unsafe here because the ext-system / licence context lives *outside* the serialized filter, so a bookmark could restore filter values belonging to a different ext-system or licence. (admin-cms keeps it enabled because its scope *is* a filter field.)
- **List ordering defaults revisited.** The labs ordering dropdown defaults `variant` to `id` where the previous component defaulted to `default` (= `createdAt`), so lists passing no variant silently switched to id ordering. Sorting by `id` stays the convention where it is meaningful (indexed primary key, higher id = newer row); only lists where `id` is provably not chronological moved to `createdAt` — imported data (`user`, `anzuUser`, `assetLicence`, `assetLicenceGroup`, `extSystem`, verified against the API) and UUID ids mixing UUIDv6/v7 (`distributionCategory`, `distributionCategorySelect`, `author`, `keyword`).
- **Date-range filters relabelled** to the "od - do" wording admin-cms uses. The `from`/`until` pairs (`createdAtFrom/Until`, `startedAtFrom/Until`) were merged into a single range control that kept only the "from" label, which made the second bound look removed — both ends stay reachable through the control's *Custom* option.
- Distribution-category-select lists search by `serviceSlug` ("Meno") in the main filter bar instead of the hidden `id` column; `id` remains available under *More*.
- **Runtime behaviour:** ext-system config access now falls back silently (`?.` + `?? fallback`) where it previously could throw on a missing `DamExtSystemConfig(Item)` field.
- **Public export create** binds to a licences **array**. [[#84735](https://dev.azure.com/petitpress/Anzu/_workitems/edit/84735)]
- Migrated 140 Vuetify-v4 lint issues automatically, plus manual v4 fixes.
- `ROUTE.X.Y` references (~290 spots) replaced by raw route-name literals; `ActionbarWrapper` uses the strict typed-router types.
- Cypress e2e specs updated to the pluralized route paths (`cy.visit()` / `cy.urlContains()` across 33 spec files).
- `@vueuse/core` / `@vueuse/integrations` pinned to an exact version; `Auth.ts` → `simpleLogin.ts` (case-collision fix); `@tsconfig/node22` → `node24`; many files reformatted by `oxfmt`.
- Bumped versions of dependencies
  - `vuetify` `^3.11.8` → `^4.1.8`
  - `vue-router` `^5.0.2` → `^5.2.0`
  - `pinia` `^3.0.4` → `^4.0.2`
  - `vue` `3.5.28` → `3.5.41`

  - `@anzusystems/common-admin` `1.47.0-beta.357` → `1.47.0-beta.dev-1784059876`
  - `@tiptap/*` `^3.19.0` → `^3.30.0`
  - `@sentry/vue` `^10.38.0` → `^10.70.0`
  - `axios` `^1.16.1` → `^1.19.0`
  - `uuid` `^13.0.2` → `^14.0.1`
  - `@vueuse/core` / `@vueuse/integrations` `14.2.0` → `14.4.0`
  - dev tooling: cypress, sass, vue-tsc, `@vitejs/plugin-vue`, `@stylistic/eslint-plugin`, `@intlify/unplugin-vue-i18n`, `eslint-plugin-vue`; `dotenv` added

### Removed

- Prettier (`prettier`, `@vue/eslint-config-prettier`) — replaced by `oxfmt`.
- `src/router/routes/` (21 files) and the `ROUTE` constants; `AEmptyRouterView` wrappers.
- Top-level `src/{components,composables,services,stores,types,model,views,utils}/` (relocated into `src/domains/` / `src/shared/`).
- Explicit imports of now-auto-imported symbols; `dark` / `contain` prop usages.
- **Dead asset filters** — the `shortestDimension` filter and the `licences` filter field. core-dam's `AssetQueryFactory` never applied either, so the API silently returned unfiltered results (verified: an unknown licence id changes nothing, while `codecName` correctly narrows to zero).

### Fixed

- **`/assets` returned 403 on hard load / refresh / deep-link.** The SPA route `/assets` collided with the Vite build dir `dist/assets/` under nginx `try_files`; nginx now serves `index.html` for `/assets` (`docker/app/local/bin/start-command`). Production (Cloudflare Pages) was unaffected.
- **Distribution-category filter returned 500.** The service-slug filter carried a wrong `apiName: 'name'`; the entity is filterable by `serviceSlug`, so `filter_*[name]` made core-dam fail — which broke opening and creating a distribution category as well as the "Meno" list filter.
- **Filters rendered as a bare field name.** The `anzuUser` `id` / `email` / `enabled` / `lastName` filters had no `type`, so `createFilter` fell back to `custom` and `FilterDetailItem` rendered `AFilterEmpty`.
- **Duplicated filter controls.** Fields bound in a `#search` slot were rendered a second time in the advanced panel; they now carry `render: { skip: true }` (21 fields across 19 filter configs).
- **Seven list filters lost their main filter bar** after the labs migration and offered only the *More* button; they got a `#search` slot back, `enable-top` / `#top` was restored for the mandatory `type` on both distribution-category pages, and `hide-more` on `assetLicenceGroup`.
- **Distribution create dialog returned contradictory results.** The distribution filter store was a module-level singleton — `DistributionBlockedBy` wrote `distributionServicesIn` / `NotIn` into it and never cleared them, so the dialog's refetch emitted `eq X + notIn X` and the sidebar list reusing the same store stayed empty until a full page reload. The store is now built per call.
- **`/jobs` crashed on an unregistered job resource** — `JobResourceChip` called `option.title` on the `undefined` returned by `getJobResourceOption`.
- **Infinite spinners on failed fetches** — the distribution-category create dialog, the asset-detail distribution sidebar and `DistributionCategoryWidget` each left a loader spinning forever (and swallowed the rejection) when the request failed; they now clear the loader and show the standard error alert. *(The underlying core-dam 500 on the category-select fetch is a separate backend task.)*
- **Keyword and author list sorting.** Every keyword fetch overwrote the sort with a hardcoded `createdAt ASC`, so the list ignored the dropdown; the sort is now dropped only while a text search is active and the user's choice is restored when the search is cleared. Author relevance ordering during a text search, lost in the migration, is back.
- `videoShowEpisode` gained a *by position* ordering option matching its actual initial sort; `ttsNarrationRequest` started with no sort while showing an id-based label; the `distributionCategory` `id` filter was typed as integer although the entity id is a UUID.
- **Slovak and English translations audited across all 35 locale-file pairs** (810 keys each, identical parity, ordering and nesting). User-visible breakage fixed: 14 English API error messages were placeholder text and shown on every forbidden-operation response; all 8 English asset-list table headers were raw lowercase field names; the English distribution `showAdvanced` / `hideAdvanced` labels were identical so the toggle never changed; the Slovak `assetLicence` internal-rule labels were half English and ungrammatical. Also fixed leftover English inside Slovak strings, Slovak diacritics and grammar, labels that were raw field or PHP class names, and inconsistent wording for the same concept. "Meno" now means a person's given name only — entities use "Názov".
- **Missing i18n dialog titles** — added the missing `coreDam.*.meta.create` keys for `podcastEpisode` / `authorCleanPhrase` / `publicExport`, which rendered raw keys.
- **Voice-family detail console error** — `VoiceBindingsList` now provides `DatatablePaginationKey`, fixing the `Incorrect provide/inject config.` thrown on the detail view.
- Post-action redirects in `distributionCategoryActions` / `assetLicenceGroupActions` pointed at the wrong list/domain route (uncovered by the route-reference audit).
- Podcast export-data temp ids are stripped on save.
- Author lists are ordered by `createdAt` instead of `id`.
- Dark-theme active-filter chips are readable and the English `filterPlaceholder` no longer shows Slovak text — both fixed upstream in common-admin, the temporary local overrides were removed.
